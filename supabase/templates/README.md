# Plantillas de correo de Supabase Auth

Generadas con `npx tsx scripts/build-auth-email-templates.mjs`. No editar a mano.
Se pegan en el panel: Authentication > Emails > Templates (ver docs/16-EMAIL-SMTP.md).

| Plantilla del panel | Archivo | Asunto |
|---|---|---|
| Confirm signup | `confirmation.html` | Confirma tu correo para entrar en Ciberan |
| Reset password | `recovery.html` | Cambia tu contraseña de Ciberan |
| Change email address | `email_change.html` | Confirma tu nuevo correo en Ciberan |
| Magic link | `magic_link.html` | Tu enlace para entrar en Ciberan |
| Invite user | `invite.html` | Te han invitado a Ciberan |
